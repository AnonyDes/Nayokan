Publishing workflow (applies to Article, Page, Programme, Story, Impact metric)
${['Draft','Submitted','In review','Approved / Changes requested','Scheduled','Published'].map((s,i) => `
STEP ${i+1}
${s}
`).join('')}
Every state transition is audited. Approvals require reviewer role. Publish requires visibility toggle + verified prerequisites.
