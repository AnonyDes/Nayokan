Nayokan · Internal Systems · v0.1

The operating layer behind Nayokan's digital ecosystem.

Nayokan Admin is the internal content management, programme operations and institutional governance platform. It is where staff manage articles, programmes, applications, opportunities, people, partners, portfolio, hospitality, impact metrics, enquiries, users and everything that appears on the public Nayokan website. Precise. Institutional. Trustworthy.

47 screens designed
4 Nayokan worlds
6 user roles
13 content entities
WCAG 2.2 AA target
Start with the Dashboard to see the content governance snapshot, or jump directly to a specific area. Every screen shares the same shell, component library and status vocabulary — the CMS is one coherent product.
